# Presence

Presence is the desktop app for **Sudo**, the desk companion by
[Presence Labs](https://www.presencelabs.in). It puts Sudo on your Wi-Fi,
connects it to your account, and lets you make it yours.

**Setting up a new Sudo? Start at [presencelabs.in/start](https://www.presencelabs.in/start).**

## Download

| System | File |
|---|---|
| Windows 10 or 11 | [Presence-windows-x64-setup.exe](https://github.com/krishnabansal89/presence-app/releases/latest/download/Presence-windows-x64-setup.exe) |
| macOS (Apple Silicon and Intel) | [Presence-macos-universal.dmg](https://github.com/krishnabansal89/presence-app/releases/latest/download/Presence-macos-universal.dmg) |
| Linux, 64-bit (AppImage) | [Presence-linux-x86_64.AppImage](https://github.com/krishnabansal89/presence-app/releases/latest/download/Presence-linux-x86_64.AppImage) |
| Linux, 64-bit (.deb) | [Presence-linux-amd64.deb](https://github.com/krishnabansal89/presence-app/releases/latest/download/Presence-linux-amd64.deb) |

Each release includes `SHA256SUMS.txt` so you can check your download.

The app is in beta and isn't code-signed yet, so Windows and macOS warn you
the first time you open it. [presencelabs.in/start](https://www.presencelabs.in/start)
shows exactly what to click.
